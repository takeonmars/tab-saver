# TabSaver

Расширение Chrome для сохранения открытых вкладок в карточки с группами и превью.
Помогает разгрузить браузер от сотни открытых вкладок и держать их в порядке.

## Возможности

- **Сохранение вкладок** — текущей или сразу нескольких (выбор с `Shift`), с опцией «сохранить и закрыть».
- **Группы** — создание с именем, переименование, удаление; распределение карточек перетаскиванием (drag & drop).
- **Теги-фильтры** — быстрый показ вкладок только выбранной группы.
- **Два режима отображения** — карточки и компактный список.
- **Превью** — `og:image` страницы или сжатый мини-скриншот (WebP), иначе favicon.
- **Хранение** — рабочие данные в `chrome.storage.local`; синхронизация в файл `tabsaver.json` на диске (File System Access API) с подсветкой устаревшей синхронизации.

## Установка (распакованное расширение)

1. Клонировать репозиторий в постоянную папку:
   ```bash
   git clone <URL> tabsaver
   ```
2. Открыть `chrome://extensions`.
3. Включить **«Режим разработчика»** (справа вверху).
4. Нажать **«Загрузить распакованное»** и выбрать папку `tabsaver`.
5. Закрепить иконку через меню «пазл» 🧩.

После `git pull` с обновлениями — нажать ↻ «Обновить» на карточке расширения.

## Структура

| Файл | Назначение |
|------|-----------|
| `manifest.json` | Манифест (MV3), права: `tabs`, `storage`, `activeTab`, `scripting` |
| `background.js` | Service worker |
| `popup.*` | Попап: список вкладок, мультивыбор, выбор/создание группы |
| `dashboard.*` | Страница со списком карточек, группами, фильтрами, синхронизацией |
| `storage.js` | Модель данных: вкладки, группы, превью, экспорт/импорт |
| `icons/` | Иконки 16/48/128 |

## Данные и бэкап

Сохранённые вкладки хранятся в профиле Chrome, а не в этой папке.
Для переносимого бэкапа нажмите **«Синхронизировать с файлом»** — данные запишутся в
`tabsaver.json` (в репозиторий он не коммитится, см. `.gitignore`).
